# 交付与验收

## HTML 预览

使用正常阅读入口检查封面、正文、附页和封底，验证翻页和跳转。预览样式里的交互控件放在书页之外。打开本地交付文件并实际检查资源加载。若改的是已有书页，用页码和图位比对源稿及改动后的页面。

## 电子书 PDF

- 沿用确认的页面尺寸与阅读顺序。常规电子书按单页阅读，印刷拼版、印刷专用空白页和网页交互控件只有在有交付要求时才收入。电子封面可沿用已批准的数字材质效果。
- 以保留真实文字层的方式导出，验证能搜索、选取和复制正文。按需要添加目录书签，检查链接目标、书名、页数和纸张尺寸。大文件可在保持成品所需清晰度的前提下压缩图片。
- 必须渲染最终 PDF 进行视觉验收。逐页检查页边、文字、衬边、图像与背景。放大查看新替换的图片及密排页。导出后若再合并或压缩，重新渲染，重点核对图片与透明叠印效果。

## 可编辑 InDesign 印刷包

- 确认印方要求的裁切尺寸、出血、装订和封面材料。书脊尺寸取决于实际装订结构及印方给的模板。尺寸未定时提供可编辑的书脊设计，并标明待定数据。
- 交付物可以是可编辑 INDD、兼容交换用 IDML，以及配套链接图和许可允许打包的字体，具体按约定。正文保留可编辑文本框，图片保留独立图框和可解析链接。重新打开目标文件，检查缺字、字体替换、缺图、溢排、有效分辨率、页序和最终替换图。
- 封面实际使用布或纹理纸时，按确认的工艺处理数字纹理。布料本身提供的纹理通常无需叠印。深色材料是否需要底色、白墨、烫印或其他工艺，按印方的材料样与打样结果决定。
- 印刷 PDF 的色彩、出血与 PDF 标准沿用印方要求。可编辑文件与印刷 PDF 分别验收。若当前环境无法打开原生文件，准确说明实际验证的格式和仍待确认的项目。
